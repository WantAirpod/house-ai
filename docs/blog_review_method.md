# 블로그 검토 방법

부동산 후보 단지의 블로그 검토는 실거래가나 세대수 판단을 대체하지 않는다. 목적은 실거주 리스크와 생활 만족도 신호를 보강하는 것이다.

## 검토 단위

- `신축만 TOP10`과 `구축 포함 TOP10`에 등장한 후보만 대상으로 한다.
- 최근 실거래 9억원 이상 10억 5천만원 이하이며 역 도보 23분 미만인 후보만 검토 대상으로 삼는다.
- 같은 단지가 여러 평형으로 등장하면 대표 평형 1개만 블로그 검토 대상으로 삼는다.
- 300세대 이하 단지는 모든 TOP10과 블로그 검토 대상에서 제외한다.
- 같은 단지가 여러 섹션에 반복되면 중복 URL은 1개 근거로만 계산한다.
- 후보별 최소 10개 이상의 블로그 검색 결과를 확인한다.

## 검색 원칙

- 기본 검색어: `단지명 아파트 장점 단점`
- 보강 검색어: `단지명 지역명 실거주 후기`
- 검색 결과가 10개 미만이면 `외부자료 부족`으로 표시한다.
- 제목과 요약만으로 단정하지 않고, 본문 확인이 필요한 항목은 `본문 확인 필요`로 남긴다.

## 반드시 보는 키워드

장점 신호:

- 역세권, 신분당선, 도보, 출퇴근
- 신축, 커뮤니티, 대단지, 브랜드
- 조용함, 산책, 공원, 조망, 일조
- 학군, 초등학교, 어린이집, 상권, 마트, 병원

단점 신호:

- 역 멂, 언덕, 버스 의존, 출퇴근 정체
- 주차난, 소음, 층간소음, 벌레, 냄새
- 하자, 누수, 관리비, 노후, 수리비
- 상권 부족, 학교 거리, 공급 리스크, 고점

필수 확인 키워드:

- 주차, 관리비, 하자, 누수, 소음, 층간소음
- 초등학교, 학군, 병원, 마트, 상권
- 역 도보, 버스, 자차 정체, 신분당선
- 커뮤니티, 조경, 동간거리, 일조, 조망

## 판정 기준

- `충족`: 중복 제거 후 블로그 결과 10개 이상
- `부족`: 1~9개
- `없음`: 0개

## 주의사항

- 분양 홍보성 글, 중개성 글, 복붙성 글은 신뢰도를 낮게 본다.
- 장점 키워드가 많아도 실거래/호가/세대수 조건을 뒤집지 않는다.
- 단점 키워드는 매수 제외 사유가 아니라 현장 확인 질문으로 전환한다.
- 블로그 결과는 최신성이 낮을 수 있으므로 관측일을 함께 기록한다.
